## ⚡ Posting Strategy

- **Frequency:** Week mein 4–5 reels
- **Order:** Mix categories — mindset, money, lifestyle rotate karo
- **Hook rule:** Zero intro. Seedha first line pe start.
- **Subtitles:** Hamesha — 80%+ log bina sound ke dekhte hain
- **Science angle:** Jab bhi data/fact mention karo — authority build hoti hai

## 🎬 Quick Shoot Checklist

- [ ] Hook line screen pe ya bol ke — first 1.5 sec

- [ ] Bold subtitles — mobile readable
- [ ] CTA specific hai? ("Comment mein likh" > "Like karo")
- [ ] Apni real story/observation add ki? (+trust)
